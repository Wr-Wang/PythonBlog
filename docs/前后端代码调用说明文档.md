## 2. 总体架构与调用链

## 2.1 架构概览

- **前端**：Vue 3 SPA（Vite 构建），通过 Axios 访问 `/api/*`
- **后端**：FastAPI（Uvicorn），提供业务 API、`/uploads`、以及可选的 `frontend/dist` 托管
- **数据层**：SQL Server（SQLAlchemy ORM + pyodbc）
- **认证**：JWT（Bearer Token）

## 2.2 端到端调用链

1. 页面触发操作（`views/*.vue`）
2. 调用 `src/api/*.js` 封装方法
3. 统一走 `src/api/http.js`（注入 token、统一错误处理）
4. 请求进入 FastAPI `routers/*`
5. 依赖注入（如鉴权、DB Session、限流）
6. ORM 查询/写入（`models/*` + `schemas/*`）
7. 返回 JSON，前端渲染状态

## 4. 代码结构说明

## 4.1 顶层结构

- `frontend/`：前端工程
- `backend/`：后端工程
- `database/`：数据库初始化与全量结构脚本
- `docs/`：需求、架构、设计、部署文档

## 4.2 前端结构（核心）

- `src/main.js`：应用启动入口
- `src/App.vue`：全局布局、主题、顶栏
- `src/router/index.js`：路由定义 + 守卫策略
- `src/api/http.js`：Axios 单例、请求/响应拦截
- `src/api/*.js`：按资源划分 API 封装（posts/users/comments...）
- `src/views/`：页面层（公共页 + 后台页）
- `src/components/`：复用组件（分页、弹窗、确认框等）
- `src/composables/`：复用逻辑（如 `useAdminListPage`）
- `src/utils/`：工具函数（权限、渲染、会话等）
- `src/style.css`：全局设计变量与通用样式

## 4.3 后端结构（核心）

- `app/main.py`：FastAPI 组装入口（路由/中间件/静态资源）
- `app/config.py`：配置项定义与读取
- `app/database.py`：Engine/Session/Base
- `app/lifespan.py`：启动生命周期（初始化、调度）
- `app/deps.py`：通用依赖（认证、权限上下文）
- `app/routers/*.py`：API 路由层（按业务域拆分）
- `app/services/*.py`：业务逻辑复用层
- `app/models/*.py`：ORM 数据模型
- `app/schemas/*.py`：请求/响应 DTO（Pydantic）
- `app/rate_limit.py`：限流策略
- `app/captcha_service.py`：验证码签发/校验/一次性消费

## 5. 层级说明（前后端）

## 5.1 前端层级

- **View 层**：用户交互与状态展示（Vue 页面）
- **Composable 层**：跨页面复用逻辑（分页、筛选、会话）
- **API 层**：接口方法封装，不在页面里直写 URL
- **HTTP 基础层**：统一认证、错误规范、超时、重定向

## 5.2 后端层级

- **Router 层**：入参校验、鉴权、HTTP 协议语义
- **Service 层**：复杂业务逻辑与规则编排
- **Model 层**：数据结构、关系与持久化映射
- **Schema 层**：外部契约（请求/响应数据边界）
- **Infra 层**：配置、数据库会话、中间件、限流、生命周期

## 6. 引用与调用说明

## 6.1 前端引用关系

- 页面通常只引用 `src/api/*.js` 与 `composables`
- `src/api/*.js` 统一引用 `src/api/http.js`
- `http.js` 统一管理：
  - Token 注入（`localStorage.blog_token`）
  - 401 处理（清理登录态并跳转后台登录页）
  - 后端 `detail` 信息合并到错误消息

## 6.2 后端引用关系

- `main.py` 统一 `include_router(...)`
- `routers/*` 依赖 `deps.py` 与 `database.get_db`
- `routers/*` 引用 `schemas/*` 作为请求/响应模型
- `routers/services` 引用 `models/*` 执行 ORM 读写

## 6.3 典型调用示例（文章后台列表）

1. `AdminPostsPage.vue` -> `adminListPosts(...)`
2. `src/api/posts.js` -> `client.get("/posts/admin", { params })`
3. `http.js` 注入 Bearer Token
4. `backend/app/routers/posts.py` 处理 `GET /api/posts/admin`
5. ORM 查询 `Post` + 关联信息
6. 返回分页结果，前端表格渲染

## 7. 关键文件作用速查

- `frontend/src/api/http.js`：请求治理中心（鉴权、错误、会话失效处理）

## 8. 使用架构说明

## 8.1 当前采用的架构模式

- **前端**：页面组件化 + API 分层 + 可复用组合式逻辑
- **后端**：FastAPI 路由模块化 + ORM + Schema 契约化
- **部署**：支持 IIS 托管，前后端可同域

## 8.2 架构优点

- 业务模块清晰，便于按域扩展（文章、专栏、工作流、RBAC）
- API 契约稳定，前后端联调成本低
- 鉴权与错误处理集中，行为一致性高
- 前端公共逻辑抽离（如分页），减少重复代码
- SQL Server 结构脚本含字段注释，交接与审计友好

## 8.3 封装优点

- **HTTP 封装**：统一 token、超时、401、错误提示格式
- **列表封装**：统一分页参数、越界页回退、401 重定向
- **会话封装**：避免重复 `auth/me` 请求，降低接口噪音
- **后端 helper/service**：聚合查询与规则复用，减少 N+1 和重复逻辑
